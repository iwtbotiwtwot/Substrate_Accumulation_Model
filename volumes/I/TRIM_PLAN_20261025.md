## 1. Principle

The trim is a change of table of contents, not of text. Whole blocks of the living text move; no line inside a moved block is edited;
nothing is deleted. The source PDF (sha256 698b2316…, 240 pages), the git history, the change log and the targets register keep every
line and the original order. Chapter numbers stay as they are (Chapter X remains "Chapter X" in the appendix) so that every existing
reference, in the closing review, the register, the extractions and the run records, still resolves. The living text is a
reading-order conversion of a two-column PDF; block edges are therefore placed at page markers or at section heads whose
neighbourhood has been checked by hand, and every moved block is hashed before and after.

## 6. Method and verification

- Branch `voli-trim-20261025` in the doc repo; tag `voli-pre-trim-20261025` on the commit before the change. Rollback is
  `git checkout voli-pre-trim-20261025 -- volumes/I/SAM_Volume_I.md volumes/I/CHANGELOG.md volumes/I/TARGETS_REGISTER_20261023.md`,
  verified on the branch before the trim is applied.
- A script `volumes/I/tools/apply_trim_20261025.py` (written after approval, committed with the change) that reads the file, cuts the
  blocks at the exact line ranges, checks each block's hash against the table in §3 before moving it, inserts the additions as
  separate lines, writes the result, and then checks: (i) each moved block's hash at its new position; (ii) the multiset of original
  lines is unchanged (the sorted lines of the new file, minus the addition lines, equal the sorted lines of the old file); (iii) line
  count = 35,403 + number of addition lines; (iv) every `<!-- page N -->` marker still present exactly once. Its report is committed
  beside it as `TRIM_REPORT_20261025.json`.
- The change log gets one line per step. The decisions file already carries Sean Brady's words of 25 October.
- Received-results sections and the drafted ceiling section are untouched; the extraction `CHART_EXTRACTION_VII_XII_20261023.md`
  gets a one-line note that Chapter X is in Appendix B.
- Volume I's chapter in the spine (`volumes/Spine/`) refers to Part 1, Part 2 and Appendix B by these names.
