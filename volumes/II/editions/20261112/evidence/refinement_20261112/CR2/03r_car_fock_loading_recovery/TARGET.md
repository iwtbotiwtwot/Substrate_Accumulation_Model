# Same-source Li6, a new N12 source and sharp continuum field loading

Reconstruct or break the submitted review claims using separate mathematical
arguments and independently authored exact/directed code. CLAIMS.json defines
every track; CONTROLS.json defines hypothesis-breaking and null checks.
RESULTS/INPUT_REFERENCE.json retains all submitted numerical assertions and
their original documents. They are assertions to test, not expected outcomes.

Use the original source, complete reference, flavor/mask/clock conventions and
declared parameter ranges. The source contract keeps changed constructions
explicit. Earlier proof/code/native evidence is available for definition and
comparison; running its existing script alone does not reconstruct the claim.
Each new attempt has timestamped predictions and code/input hashes before
execution, with every failed version retained. A replay must use public case
inputs, standard documented dependencies and no installed research engine.

Return a complete proof, fresh runner and full claim/control outcomes. Review
and fresh relocated replay determine reached independence/reproducibility.
No fixed deadline, expected positive verdict, manuscript edit or engine change
is part of this verification case. New observations are recorded separately.
