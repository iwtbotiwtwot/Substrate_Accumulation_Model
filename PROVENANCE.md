# Provenance

- **Sources of record.** The three PDFs under `volumes/*/source/` as delivered by Sean Brady on 2026-10-19 from his Downloads
  folder; their sha256 are in each `SOURCE.json` and in `SHA256SUMS`. The living Markdown was produced from them with
  `pdftotext -layout` and is the editable text from then on.
- **Runs.** Each `runs/<date>_<name>/RECORD.md` names the ironclad campaign folder, the ironclad commit, the history entry
  (H00xxxx) and the run id; the retained ledgers and native results live in ironclad (`campaigns/*/results/`,
  `runs/duck/*`, hashes in each campaign's `RESULTS_MANIFEST.json`). Nothing bulk is copied here.
- **Changes to the text.** `volumes/<N>/CHANGELOG.md`, one line per change with the run or decision behind it; the git history
  carries the diff.
- **Decisions and ideas.** `decisions/DECISIONS.md` (Sean's words, dated); `ideas/IDEAS.md` (status changes only by Sean).
- **Hashes.** `SHA256SUMS` is regenerated by `scripts/conclude.sh` at every conclusion and covers every tracked file except
  itself.
